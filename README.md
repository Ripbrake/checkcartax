# checkcartax.com

Static rebuild of checkcartax.com. Plain HTML/CSS, generated by `build.py` (Python 3, no dependencies).

- Content: `src/content.py` (VED facts from GOV.UK; rates from 1 April 2026), legal text in `src/legal/`, styles in `src/style.css`.
- Build: `python3 build.py` writes the pages into the repo root (`about.html` is served at `/about` by GitHub Pages; `free-car-tax-check/index.html` at `/free-car-tax-check/`).
- Optional env vars: `GA_ID` (Google tag, loaded after page load; the old site had none), `GSC_VERIFICATION` (Search Console meta tag), `LASTMOD`.
- The reg form sends users to `https://secure.checkmot.com/mot/search?id=checkmotv2&reg=<REG>` (uppercased, spaces stripped).
